We support self-hosting with Containers for example:

- [Docker](/docs/self-hosting/docker)
- [Kubernetes](/docs/self-hosting/kubernetes)

To have an easy way to deploy LinkShelf we bundled your backend and frontend into one image and tried to minimize the
size of the image. We consider to provide two more images one specific for the frontend and one for the backend, however
this has not been done yet. At the moment there is just one image (`ghcr.io/m-mattia-m/linkshelf:latest`) availabe which
includes the backend and frontend.
